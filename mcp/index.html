Connect AfterMath directly to Google Gemini on the web at gemini.google.com via native Streamable HTTP:

  1. Go to gemini.google.com on your computer.
  2. In the left sidebar, click Settings & help > Connected Apps (or Personal Intelligence > Connected Apps).
  3. Under Custom apps, click Add a custom app.
  4. Paste the Streamable HTTP server URL: https://ah.mphinance.com/api/mcp
  5. Click Next / Connect (Zero API key or authentication required).
Gemini Web MCP URL (Streamable HTTP) 
https://ah.mphinance.com/api/mcp
⚠️ Important: Do not use /sse. Gemini Web requires the Streamable HTTP endpoint (/api/mcp). Entering /sse triggers "The MCP server could not be reached. Check the URL".

Add the AfterMath MCP server to Google Gemini CLI & Antigravity. Note: Gemini requires explicit --transport sse (otherwise it defaults to stdio and errors with "The MCP server could not be reached. Check the URL"):

bash 
# 1. Native Gemini CLI with SSE transport
gemini mcp add aftermath https://ah.mphinance.com/sse --transport sse

# 2. Or add to Antigravity CLI via mcp-remote
agy mcp add aftermath-remote --command npx -- -y mcp-remote https://ah.mphinance.com/sse

# 3. Verify connection
gemini mcp list
# Output: ✓ aftermath: https://ah.mphinance.com/sse (sse) - Connected

Or add directly to .gemini/settings.json with "type": "sse" and "url": "https://ah.mphinance.com/sse".

Download and run the zero-dependency Python script directly on any system with Python 3.8+:

bash 
# 1. Download standalone server
curl -sSL https://ah.mphinance.com/mcp_server.py -o aftermath_mcp.py

# 2. Run diagnostic self-test
python3 aftermath_mcp.py --test

# 3. Start local SSE daemon on port 8089
python3 aftermath_mcp.py --port 8089

# 4. Or use in local STDIO mode
python3 aftermath_mcp.py

Execute MCP tools directly over HTTP JSON-RPC 2.0 without maintaining an SSE connection:

bash (cURL) 
curl -s -X POST https://ah.mphinance.com/api/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "get_market_tape",
      "arguments": {}
    }
  }'
