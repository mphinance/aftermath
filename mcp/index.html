Connect AfterMath directly to Google Gemini on the web at gemini.google.com via native Streamable HTTP:

  1. Go to gemini.google.com on your computer.
  2. In the left sidebar, click Settings & help > Connected Apps (or Personal Intelligence > Connected Apps).
  3. Under Custom apps, click Add a custom app.
  4. Paste the Streamable HTTP server URL: https://ah.mphinance.com/api/mcp
  5. Click Next / Connect (Zero API key or authentication required).
Gemini Web MCP URL (Streamable HTTP)

⚠️ Important: Do not use /sse. Gemini Web requires the Streamable HTTP endpoint (/api/mcp). Entering /sse triggers "The MCP server could not be reached. Check the URL".

Add the AfterMath MCP server to Google Gemini CLI & Antigravity. Note: Gemini requires explicit --transport sse (otherwise it defaults to stdio and errors with "The MCP server could not be reached. Check the URL"):

bash 
# 1. Native Gemini CLI with SSE transport
gemini mcp add aftermath https://ah.mphinance.com/sse --transport sse

# 2. Or add to Antigravity CLI via mcp-remote
agy mcp add aftermath-remote --command npx -- -y mcp-remote https://ah.mphinance.com/sse

# 3. Verify connection
gemini mcp list
# Output: ✓ aftermath: https://ah.mphinance.com/sse (sse) - Connected

Or add directly to .gemini/settings.json with "type": "sse" and "url": "https://ah.mphinance.com/sse".

🛠️ The 6 Production MCP Tools

Standard JSON-RPC tools exposed to your language model
mcp-schema.json ↗
MACRO TAPE
get_market_tape
Retrieves real-time macro tape overview: whale cash reserves ($8.98M dry powder), intraday net P&L, equity/ETF allocation ratio, and top capital inflow leaders.
Inputs: None (global market state)
SECURITY SCREENER
get_top_equities
Filters and ranks 500 verified stocks with customizable thresholds for whale capital, owner count, conviction intensity, and asset segregation.
Inputs: limit, min_whale_capital, min_conviction, min_owners, asset_type, sort_by
ETF RADAR
get_etf_flows
Inspects 64 ETFs & index funds ranked by whale capital backing, expense ratios, asset classes (equity, broad market, thematic, crypto), and retail crowd breadth.
Inputs: limit, sort_by
FORENSIC AUDIT
get_whale_portfolio
Audits any verified whale account by username (e.g. SIRJACK, thealexperez) to inspect verified positions, cost basis, profit, cash balance, and shadow ratio.
Inputs: username (required)
SECURITY DEEP-DIVE
get_ticker_intel
Forensic intelligence on any ticker ($NVDA, $ASTS, $AAPL, etc.) with verified holders, conviction intensity ($/sub), top whale holders, and optional 90-day daily OHLCV bars.
Inputs: ticker (required), include_bars (boolean)
ASYMMETRIC CONVICTION
get_conviction_screener
Scans for asymmetric high conviction where average position per holder exceeds a given threshold (e.g. $50k or $100k), revealing quiet institutional accumulation.
Inputs: min_intensity, min_owners, limit
